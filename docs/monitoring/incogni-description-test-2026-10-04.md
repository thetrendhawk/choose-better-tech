# Incogni description test — October 4, 2026

## Scope and evidence

One description change on `/reviews/incogni-review`, accompanied at deployment by an explicit documentation-only testing disclosure in the executive summary. Existing title, H1, publication/update dates, product claims, verdict, affiliate status and destinations remain unchanged. The timeline description experiment remains frozen separately. The disclosure is a concurrent change and must be recorded as a possible confounder in future evaluation.

Search Console Web report observed October 4: September 2–29 page baseline 1 click, 669 impressions, displayed CTR 0.1%, average position 9.8. Exact-page query rows: `reviews of incogni` 93 impressions / position 4.9; `incogni reviews` 79 / 5.4; `incogni review` 56 / 6.8; `is incogni legit` 23 / 6.0. Each has zero recorded clicks. This is a small-sample hypothesis, not evidence that the current description caused low CTR.

Sitewide comparison queries rank materially lower: `dropbox vs drive` 90 impressions / position 60.0, `google drive vs dropbox` 39 / 72.1, `incogni vs deleteme` 85 / 28.5 and `incogni vs optery` 59 / 28.9. Broad metadata changes are not justified by zero clicks alone.

Country/device tabs were inspected, but their visible row totals did not reconcile with the page card. Do not calculate shares or assert segment-specific performance from those partial snapshots. Primary interpretation uses the exact-page query view. Private raw snapshots are retained locally.

## Hypothesis and copy

Readers searching for reviews may prefer a concise preview of removal limits and alternatives to a list of topics. New copy describes sections already in the article; no new product or hands-on claim is introduced.

Before: Does Incogni work? Our 2026 review examines data-broker removals, pricing, recurring requests, Deloitte assurance, privacy tradeoffs, and who should use it.

After: Incogni review: see how recurring broker removals work, what the service cannot erase, privacy tradeoffs, and when to choose an alternative.

[Google's snippet documentation](https://developers.google.com/search/docs/appearance/snippet) explains that descriptions should accurately summarize a page and that Google can choose page content instead. Deployment does not prove adoption of the description.

## Evaluation and rollback

Exclude October 4 deployment day. Earliest full 28-day post-deployment window: October 5–November 1; compare September 6–October 3 only when that baseline is fully available in GSC. Retain the September 2–29 snapshot as the opportunity baseline, not a substitute matched experiment window. At review, inspect crawl/adoption evidence, exact page and the same queries, impressions, clicks, CTR and position; check geography/device only after reconciling exports. Record intervening changes and Google snippet variation. At these traffic levels, a few clicks cannot establish a causal winner.

Hold other metadata/body changes on this page during observation unless correcting a factual or technical defect. Restore the previous description if inaccurate or if adequate comparable evidence supports reversal. No ranking or revenue uplift is claimed.
